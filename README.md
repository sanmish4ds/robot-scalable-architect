# robot-scalable-architect

This repository contains the manuscript and artifacts for **“Real-Time Intelligence and Scalable Architecture for Robotics”**, plus small reproducible tools used in the paper.

## Journal submission (Complex & Intelligent Systems, double-blind)

See [`Real_Time_Intelligence_and_Scalable_Architecture_for_Robotics (2)/SUBMISSION.md`](Real_Time_Intelligence_and_Scalable_Architecture_for_Robotics%20(2)/SUBMISSION.md).

- **Blind manuscript:** `main_blind.pdf` (build with `latexmk -pdf main_blind.tex`)
- **Title page + declarations:** `title_page.pdf`
- **Supplementary (blinded):** run `package_supplementary.sh` in the paper folder

## TIC monitor (software-only)

See `tic_monitor/` for a reference **TIC monitor + CAAI supervisor** implementation (no ROS 2 required).
